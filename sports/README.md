# ⚽ LUKA 스포츠 — 광고·댓글 없는 클린 스포츠 앱

아이(초1)가 혼자 열어도 안전한 스포츠 화면입니다.
네이버 스포츠의 **경기·순위·기사 제목/요약**만 받아서, 광고·배너·댓글·자극적인 기사 없이 보여 줍니다.

- **앱 주소**: https://yuuunjk.github.io/clean-sports/
- **만든 방식**: 정적 HTML 한 장 + 5분마다 도는 GitHub Actions 데이터 수집

## 화면

| 탭 | 내용 |
|---|---|
| 🔴 오늘 경기 | 전 종목 오늘 경기. LIVE / 예정 / 종료로 나눠서 팀 엠블럼·큰 스코어·세트·이닝 표시 |
| 🏆 순위 | 리그 선택 → 순위·경기·승·무·패·승률(또는 승점)·최근 5경기. 우리 팀은 노란 줄 |
| 📰 주요 소식 | 종목별로 골라 낸 기사의 **제목 + 3줄 요약 + 언론사/시각 + 원문 링크** |
| ⚙️ 설정 | 우리 팀 즐겨찾기, 자동 새로고침 간격, 마지막 업데이트·실시간 연결 상태 |

종목 필터: 전체 · 야구 · 해외야구 · 축구 · 해외축구 · 농구 · 배구 · 골프 · 일반

## 데이터

`scripts/fetch_sports.py`가 네이버 스포츠 공개 API에서 받아 만듭니다.

| 파일 | 내용 |
|---|---|
| `data/today.json` | 오늘 경기 전 종목 (상태·스코어·엠블럼·구장·중계) |
| `data/standings.json` | 리그별 팀 순위 (KBO·MLB·NPB·K리그1/2·EPL·라리가·분데스리가·세리에A·MLS·KBL·WKBL·NBA·V리그 남/여) |
| `data/news.json` | 안전 필터를 통과한 기사 제목 + 규칙 기반 3줄 요약 + 원문 링크 |
| `data/news_cache.json` | 이미 요약한 기사 캐시 (본문 재요청 방지) |

지키는 선:

- 기사 **전문은 저장하지 않습니다.** 요약을 만든 뒤 버리고, json에는 제목·요약·링크만 남깁니다. 댓글·광고는 받지도 않습니다.
- 어린이에게 부적절한 주제(사건·사고·연예·정치·도박·성 관련 등)는 제목 단계에서 걸러 냅니다.
- 외부 AI API를 쓰지 않습니다. 문장 추출 + 제목 키워드 겹침 점수로 3줄을 만듭니다(비용 0원).

## 갱신

`.github/workflows/update-sports.yml` — `*/5 * * * *` (5분마다) + 수동 실행(`workflow_dispatch`).
수집 → `data/` 커밋 → GitHub Pages(main 브랜치 루트)가 그대로 서빙.

앱은 브라우저에서도 네이버 API 직접 호출을 시도합니다(CORS 허용 시 `🔄 실시간` 토글 30초 갱신).
막혀 있으면 5분 주기 JSON + 🔄 새로고침으로 동작합니다.

## 설치 (삼성 인터넷 / 안드로이드)

1. 태블릿에서 https://yuuunjk.github.io/clean-sports/ 열기
2. 주소창 오른쪽 메뉴 → **홈 화면에 추가** / **웹앱 설치**
3. 앱 아이콘(축구공)이 생깁니다. `manifest.webmanifest` + 180/192/512 PNG 아이콘 제공.
